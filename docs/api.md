# CareCue — Backend API Specification

> Serverless HTTP API Specification for CareCue Healthcare Information Companion

---

## Base URL
- Local Dev: `http://localhost:3001` (SAM Local)
- Production: `https://<api-id>.execute-api.<region>.amazonaws.com`

All endpoints return and accept `Content-Type: application/json`.

---

## 1. Sessions API

### `POST /sessions`
Creates a new care session.

**Request Body:**
```json
{
  "type": "report" | "guidance" | "brief"
}
```

**Response (201 Created):**
```json
{
  "id": "session-1718000000000",
  "type": "report",
  "status": "created",
  "createdAt": "2026-09-18T11:00:00.000Z"
}
```

---

### `GET /sessions`
Lists all recent care sessions for the user.

**Response (200 OK):**
```json
{
  "sessions": [
    {
      "id": "session-001",
      "type": "report",
      "status": "complete",
      "createdAt": "2026-09-18T10:30:00.000Z",
      "documentName": "Lab Report — Blood Panel",
      "insightCount": 6,
      "verifiedCount": 4,
      "reviewCount": 2
    }
  ]
}
```

---

### `GET /sessions/{sessionId}`
Retrieves session metadata by ID.

**Response (200 OK):**
```json
{
  "id": "session-001",
  "type": "report",
  "status": "complete",
  "createdAt": "2026-09-18T10:30:00.000Z",
  "documentName": "Sample_Blood_Panel.pdf",
  "analysisResult": { ... }
}
```

---

### `DELETE /sessions/{sessionId}`
Deletes the session record from DynamoDB and removes associated files from S3.

**Response (200 OK):**
```json
{
  "success": true,
  "sessionId": "session-001"
}
```

## 2. Document Upload API

### `POST /documents/upload-url`
Generates a short-lived (15-minute) pre-signed S3 PUT URL for direct browser upload.

**Request Body:**
```json
{
  "sessionId": "session-001",
  "fileName": "blood_work.pdf",
  "fileType": "application/pdf",
  "fileSizeBytes": 142000
}
```

**Response (200 OK):**
```json
{
  "uploadUrl": "https://carecue-documents-xyz.s3.amazonaws.com/sessions/session-001/documents/doc-123.pdf?...",
  "documentId": "doc-123",
  "s3Key": "sessions/session-001/documents/doc-123.pdf",
  "expiresInSeconds": 900
}
```

## 8. Multilingual Translation API

### `POST /translation`
Translates plain-language medical content into Hindi (`hi`) or Bengali (`bn`) with guaranteed preservation of numbers, units, and ranges.

**Request Body:**
```json
{
  "text": "Hemoglobin is 10.2 g/dL which is below standard range of 12.0 - 16.0 g/dL.",
  "targetLanguage": "hi",
  "preserveTerms": ["10.2 g/dL", "12.0 - 16.0 g/dL"]
}
```

**Response (200 OK):**
```json
{
  "originalText": "Hemoglobin is 10.2 g/dL which is below standard range of 12.0 - 16.0 g/dL.",
  "targetLanguage": "hi",
  "translatedText": "हीमोग्लोबिन 10.2 g/dL है जो 12.0 - 16.0 g/dL की सामान्य सीमा से कम है।",
  "tokensProtected": 2,
  "cached": false
}
```

## 10. Patient Management & Record Tracking API

### `GET /patients`
Retrieves registered patients with optional name/notes query filter.

### `POST /patients`
Registers a new patient profile.

### `GET /patients/{id}`
Fetches full demographic profile and record count for a patient.

### `GET /patients/{id}/documents`
Lists all documents attached to the patient chart with classifications (LAB, PRESCRIPTION, REPORT, DISCHARGE, OTHER).

### `POST /patients/{id}/documents`
Attaches a new clinical record to an established patient profile.

### `GET /patients/{id}/timeline`
Fetches chronological multi-document history with conservative biomarker comparisons.

### `POST /documents/identify-patient`
Extracts candidate patient names and birth dates from raw document text.

### `POST /documents/match-patient`
Compares extracted patient name against active target patient or full roster returning `EXACT_NAME_MATCH`, `LIKELY_MATCH`, `DIFFERENT_PATIENT`, or `NO_MATCH`.
