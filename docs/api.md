# CareCue — Backend API Specification

> Serverless HTTP API Specification for CareCue Healthcare Information Companion

---

## Base URL
- Local Dev: `http://localhost:3001` (SAM Local)
- Production: `https://<api-id>.execute-api.<region>.amazonaws.com`

All endpoints return and accept `Content-Type: application/json`.

---

## 1. Sessions API

### `POST /sessions`
Creates a new care session.

**Request Body:**
```json
{
  "type": "report" | "guidance" | "brief"
}
```

**Response (201 Created):**
```json
{
  "id": "session-1718000000000",
  "type": "report",
  "status": "created",
  "createdAt": "2026-09-18T11:00:00.000Z"
}
```

---

### `GET /sessions`
Lists all recent care sessions for the user.

**Response (200 OK):**
```json
{
  "sessions": [
    {
      "id": "session-001",
      "type": "report",
      "status": "complete",
      "createdAt": "2026-09-18T10:30:00.000Z",
      "documentName": "Lab Report — Blood Panel",
      "insightCount": 6,
      "verifiedCount": 4,
      "reviewCount": 2
    }
  ]
}
```

---

### `GET /sessions/{sessionId}`
Retrieves session metadata by ID.

**Response (200 OK):**
```json
{
  "id": "session-001",
  "type": "report",
  "status": "complete",
  "createdAt": "2026-09-18T10:30:00.000Z",
  "documentName": "Sample_Blood_Panel.pdf",
  "analysisResult": { ... }
}
```

---

### `DELETE /sessions/{sessionId}`
Deletes the session record from DynamoDB and removes associated files from S3.

**Response (200 OK):**
```json
{
  "success": true,
  "sessionId": "session-001"
}
```

## 2. Document Upload API

### `POST /documents/upload-url`
Generates a short-lived (15-minute) pre-signed S3 PUT URL for direct browser upload.

**Request Body:**
```json
{
  "sessionId": "session-001",
  "fileName": "blood_work.pdf",
  "fileType": "application/pdf",
  "fileSizeBytes": 142000
}
```

**Response (200 OK):**
```json
{
  "uploadUrl": "https://carecue-documents-xyz.s3.amazonaws.com/sessions/session-001/documents/doc-123.pdf?...",
  "documentId": "doc-123",
  "s3Key": "sessions/session-001/documents/doc-123.pdf",
  "expiresInSeconds": 900
}
```

## 4. Doctor Brief API

### `POST /doctor-brief`
Generates a concise visit preparation brief based on validated findings and optional patient notes.

**Request Body:**
```json
{
  "sessionId": "session-001",
  "userNotes": "Feeling tired lately in the mornings."
}
```

**Response (200 OK):**
```json
{
  "sessionDate": "September 18, 2026",
  "documentSummary": "Complete Blood Count (CBC) and Lipid Panel laboratory analysis.",
  "keyFindings": [
    {
      "finding": "Hemoglobin below reference range",
      "value": "10.2 g/dL",
      "range": "12.0 – 16.0 g/dL",
      "verificationStatus": "consistent",
      "discussWithDoctor": true
    }
  ],
  "discussionItems": [
    "Hemoglobin appears below reference range — discuss whether further evaluation is warranted.",
    "Total cholesterol is mildly elevated."
  ],
  "userNotes": "Feeling tired lately in the mornings.",
  "disclaimer": "This brief was generated by CareCue using AI analysis for informational purposes only. Please share it with your healthcare provider."
}
```

## 5. Care Guidance API

### `POST /guidance`
Answers informational questions with evidence references and safety boundaries.

**Request Body:**
```json
{
  "question": "What does low hemoglobin generally mean?"
}
```

**Response (200 OK):**
```json
{
  "answer": "Hemoglobin is a protein in red blood cells that carries oxygen...",
  "evidencePoints": [
    {
      "claim": "Reference ranges vary by individual factors.",
      "source": "Clinical Reference",
      "verification": { "status": "consistent", "reasoning": "Standard clinical consensus." }
    }
  ],
  "relatedQuestions": [
    "What factors influence red blood cell production?",
    "When should I discuss lab results with my doctor?"
  ],
  "safetyNote": null,
  "disclaimer": "This information is educational only and does not constitute medical advice."
}
```

## 6. Dual-AI Consensus Verification API

### `POST /verification`
Cross-checks Bedrock-extracted findings against Google Gemini (Free Tier) and source evidence quotes.

**Request Body:**
```json
{
  "sessionId": "cc-sess-001",
  "findings": [
    {
      "id": "f-1",
      "title": "Elevated Fasting Glucose",
      "plainLanguageSummary": "Fasting glucose is above standard reference range.",
      "clinicalSignificance": "Value: 118 mg/dL (Reference: 70 - 99 mg/dL)",
      "sourceQuote": "Fasting Blood Glucose: 118 mg/dL",
      "sourcePage": 1
    }
  ],
  "sourceText": "Fasting Blood Glucose: 118 mg/dL (Reference: 70 - 99 mg/dL)"
}
```

**Response (200 OK):**
```json
{
  "sessionId": "cc-sess-001",
  "status": "CONSISTENT" | "NEEDS_REVIEW" | "SAFETY_REDIRECT",
  "summary": {
    "totalInsights": 1,
    "consistent": 1,
    "needsReview": 0,
    "safetyRedirects": 0,
    "verificationEngine": "Amazon Bedrock + Google Gemini (Free Tier)",
    "consensusFraming": "Consistent with supplied evidence (non-diagnostic)"
  },
  "findings": [
    {
      "id": "f-1",
      "verificationStatus": "consistent",
      "verification": {
        "status": "consistent",
        "bedrockInterpretation": "Identified elevated fasting blood glucose.",
        "geminiAssessment": "Confirmed 118 mg/dL exceeds upper limit of 99 mg/dL.",
        "reasoning": "Consistent with the supplied evidence across primary analysis and independent cross-check.",
        "issues": [],
        "evidenceVerified": true
      }
    }
  ],
  "safetyIssues": []
}
```
